# משה הלל | הקול שנשאר

אוסף האקפלות המשפחתי של משה הלל ז״ל — הצנחן המזמר.

האתר הסטטי נמצא ב-`site/`. הוא כולל ממשק עברי מימין לשמאל, נגן HTML5, מילים, בחירה והגדלת כתב, שיתוף וקישור לבחירת שיר. אין שרת יישומים או מסד נתונים.

## פתיחת הטיוטה עם שבע ההקלטות

הארכיון הפרטי `Moshe-Hillel-Acapella-Private-Draft-Assets.zip` כולל את הקטלוג המלא, שבעה קובצי MP3 ואת שבעת קובצי ה-ODT המקוריים. חלצו אותו ל-`draft-input/` בשורש המאגר. הפעילו משורש המאגר:

```sh
mkdir -p draft
cp -R site/. draft/
cp draft-input/songs.json draft/
cp -R draft-input/media draft/
python3 -m http.server 8000 --bind 127.0.0.1 --directory draft
```

פתחו בדפדפן את [http://127.0.0.1:8000](http://127.0.0.1:8000). כתובת זו זמינה במחשב שמריץ את השרת. שרת Python מיועד לתצוגה מקומית ויש גרסאות שבהן אין תמיכה ב-HTTP Range. תצורת האירוח שב-`hosting/` מטפלת בבקשות האלה.

הטיוטה שומרת את ההקלטות ואת המילים עד לאישור זכויות השימוש והאירוח. העותק שב-`site/songs.json` כולל פרטי קטלוג, קרדיטים ומשך הקלטה. הקטלוג המלא וקובצי המקור נמצאים בחבילת הטיוטה.

## תחזוקה

1. **שיר חדש.** בעותק העבודה של הקטלוג המלא הוסיפו פריט ב-`songs` עם `id` קבוע באותיות לטיניות קטנות, ספרות או מקפים, `order` ייחודי, `title`, `performer`, `lyricist`, `composer` ו-`creditsStatus`. אם קרדיט דורש אימות השתמשו ב-`null` לשם ובתיאור מתאים לסטטוס.
2. **הקלטה.** העתיקו את ה-MP3 כפי שהתקבל לתיקיית `media/` בשם תואם ל-`id`. הוסיפו `audio` בפורמט `media/ID.mp3` ו-`duration` בשניות. אפשר למדוד באמצעות `ffprobe -v error -show_format -show_streams FILE.mp3`. השתמשו ב-`audio: null` כאשר הקובץ חסר. לעטיפה אופציונלית הגדירו `cover` כנתיב יחסי לתמונה או כ-`null`.
3. **מילים.** שמרו את שם מסמך המקור ב-`lyrics.source`, את סטטוס השיוך ב-`lyrics.status` והערת קריאה ב-`lyrics.note`. כל איבר ב-`lyrics.sections` כולל `label` כגון ״בית״ או ״פזמון״ ו-`lines`, מערך שורות לפי סדר הופעתן. לשורה שממתינה לבדיקה הכניסו אובייקט עם `status: "review"` ו-`note` בעברית. כשכל הטקסט ממתין, השאירו את `sections` ריק.
4. **סנכרון עתידי.** `lyrics.cues` שמור כרגע כמערך ריק. אפשר בעתיד להוסיף אובייקטים עם `start` ו-`end` בשניות מתחילת הקלטה ועם `section` ו-`line` כאינדקסים שמתחילים ב-0. הנגן הנוכחי מציג את המילים ללא תזמון.
5. **פורטרט.** העלו תמונת משפחה מאושרת ל-`images/` בתוך עותק האתר והגדירו `portrait` כאובייקט עם `src` יחסי ו-`alt` בעברית. כשהערך `null`, מופיע איור תקליט מופשט.
6. **נגן.** `settings.continuous` קובע את ברירת המחדל של ניגון רצוף. האתר מציע בחירה בחזרה על שיר ובחזרה על האוסף. כשהחזרה על האוסף פעילה, ניגון רצוף ממשיך מהשיר האחרון לראשון. השמעה ראשונה מתחילה בלחיצה על ניגון. השיתוף משתמש בממשק של מערכת ההפעלה כשהוא זמין, ובתיבת קישור שניתן להעתיק בשאר המקרים.
