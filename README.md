# משה הלל | הקול שנשאר

אוסף האקפלות המשפחתי של משה הלל ז״ל — הצנחן המזמר.

האתר הסטטי נמצא ב-`site/`. הוא כולל ממשק עברי מימין לשמאל, נגן HTML5, מילים, בחירה והגדלת כתב, שיתוף וקישור לבחירת שיר. אין שרת יישומים או מסד נתונים.

## הפעלה מקומית

משורש המאגר:

```sh
python3 scripts/check-pages.py site audio-inventory.json
python3 -m http.server 8000 --bind 127.0.0.1 --directory site
```

פתחו את [http://127.0.0.1:8000](http://127.0.0.1:8000) בדפדפן. שרת Python משמש לתצוגה מקומית. התנהגות בקשות Range תלויה בשרת.

`site/songs.json` כולל את מילות השירים ואת הקרדיטים. שבע ההקלטות נמצאות ב-`site/media/` בפורמט המקורי. מסמכי ODT וארכיון הטיוטה פרטיים ונשמרים מחוץ לעץ הפריסה.

## תחזוקה

1. **שיר חדש.** ב-`site/songs.json` הוסיפו פריט ב-`songs` עם `id` קבוע באותיות לטיניות קטנות, ספרות או מקפים, `order` ייחודי, `title`, `performer`, `lyricist`, `composer` ו-`creditsStatus`. אם קרדיט דורש אימות השתמשו ב-`null` לשם ובתיאור מתאים לסטטוס.
2. **הקלטה.** העתיקו את ה-MP3 כפי שהתקבל לתיקיית `site/media/` בשם תואם ל-`id`. הוסיפו `audio` בפורמט `media/ID.mp3` ו-`duration` בשניות. אפשר למדוד באמצעות `ffprobe -v error -show_format -show_streams FILE.mp3`. הוסיפו את המיפוי, נתוני ההקלטה ו-SHA-256 ל-`audio-inventory.json`. שיר שעדיין אין לו MP3 נשאר בטיוטה עד שיהיה מוכן. לעטיפה אופציונלית הגדירו `cover` כנתיב יחסי לתמונה או כ-`null`.
3. **מילים.** שמרו את שם מסמך המקור ב-`lyrics.source`, את סטטוס השיוך ב-`lyrics.status` והערת קריאה ב-`lyrics.note`. כל איבר ב-`lyrics.sections` כולל `label` כגון ״בית״ או ״פזמון״ ו-`lines`, מערך שורות לפי סדר הופעתן. לשורה שממתינה לבדיקה הכניסו אובייקט עם `status: "review"` ו-`note` בעברית. כשכל הטקסט ממתין, השאירו את השיר בטיוטה עד לבדיקת הטקסט.
4. **סנכרון עתידי.** `lyrics.cues` שמור כרגע כמערך ריק. אפשר בעתיד להוסיף אובייקטים עם `start` ו-`end` בשניות מתחילת הקלטה ועם `section` ו-`line` כאינדקסים שמתחילים ב-0. הנגן הנוכחי מציג את המילים ללא תזמון.
5. **פורטרט.** העלו תמונת משפחה מאושרת ל-`images/` בתוך עותק האתר והגדירו `portrait` כאובייקט עם `src` יחסי ו-`alt` בעברית. כשהערך `null`, מופיע איור תקליט מופשט.
6. **נגן.** `settings.continuous` קובע את ברירת המחדל של ניגון רצוף. האתר מציע בחירה בחזרה על שיר ובחזרה על האוסף. כשהחזרה על האוסף פעילה, ניגון רצוף ממשיך מהשיר האחרון לראשון. השמעה ראשונה מתחילה בלחיצה על ניגון. השיתוף משתמש בממשק של מערכת ההפעלה כשהוא זמין, ובתיבת קישור שניתן להעתיק בשאר המקרים.

## פריסה ל-GitHub Pages

1. בהגדרות המאגר, פתחו **Settings → Pages → Build and deployment** ובחרו **GitHub Actions** בשדה **Source**. ההגדרה חד-פעמית ומצריכה הרשאת מנהל במאגר.
2. כל דחיפה מתאימה ל-`main` מפעילה את התהליך **Deploy acapella site to GitHub Pages**. הוא מאמת התאמה בין הקטלוג ל-MP3 ובודק את טביעות SHA-256 של ההקלטות לפני שהוא מפרסם את `site/`. אפשר להפעיל אותו גם מתוך הלשונית **Actions**.
3. אחרי פריסה מוצלחת, פתחו את **View deployment** בחלון פרטי. בדקו ששבעת השירים מוצגים, שהנגן מבקש אודיו רק אחרי לחיצה, שהתקדמות ומעבר בין שירים עובדים, ושכל שיר מציג את מילותיו. בדפדפן נייד בדקו גם דילוג בפס ההתקדמות. הפיצו את כתובת ה-HTTPS שמופיעה בפריסה לאחר הבדיקה.

האתר ציבורי ונפתח ללא כניסה. התג `noindex, nofollow` מבקש ממנועי חיפוש שלא לאנדקס את עמוד האתר. כל מי שמגיע לכתובת יכול לפתוח את האתר ואת הקבצים שפורסמו. הפרסום של תוספות בעתיד כפוף לאישור בעל הפרויקט ולזכויות השימוש הנדרשות.
